Вопросы и ответы (Часть 1)

Вопрос 1. Для каких задач можно использовать удалённый сервер? Ответ: Хранение конфиденциальных данных
Вопрос 2. Какой ключ SSH можно безопасно пересылать по интернету? Ответ: id_rsa.pub
Вопрос 3. Команда для копирования папки `stepic` на сервер? Ответ: scp -r stepic username@server:~/
Вопрос 4. Действия при ошибке `apt-get install program`? Ответ: sudo apt-get update, проверка интернет-соединения
Вопрос 5. Назначение программы FileZilla? Ответ: Для копирования файлов с сервера на свой компьютер

Вопросы и ответы (Часть 2)

Вопрос 6. Что делать, если программе нужен графический экран? Ответ: Проверить, есть ли другая версия этой программы
Вопрос 7. Как получить справку о программе? Ответ: program --help или help program
Вопрос 8. Какие форматы данных принимает FastQC? Ответ: bam_mapped, sam_mapped, bam, sam
Вопрос 9. Команда для множественного выравнивания ClustalW? Ответ: clustalw -INFILE=test.fasta -ALIGN
Вопрос 10. Результат `jobs` после `fg %1`, `Ctrl+C`, `fg %2`, `Ctrl+Z` Ответ: Только о program2 и program3

Вопросы и ответы (Часть 3)

Вопрос 11. Одинаковы ли идентификаторы в `jobs`, `top` и `ps`? Ответ: Одинаковые только у ps и top
Вопрос 12. Команда для мгновенного завершения остановленного процесса? Ответ: kill -9
Вопрос 13. Что произойдёт при `kill` (без опций) для остановленного процесса? Ответ: Процесс приступит к завершению, как только будет продолжен
Вопрос 14. Сколько CPU использует остановленное многопоточное приложение? Ответ: 0% CPU
Вопрос 15. Сколько памяти занимает остановленное многопоточное приложение? Ответ: Столько, сколько оно потребляло в момент остановки

Вопросы и ответы (Часть 4)

Вопрос 16. Как принудительно завершить один поток многопоточного приложения? Ответ: Никак
Вопрос 17. Какие этапы bowtie2 можно выполнять в несколько потоков? Ответ: Только bowtie2
Вопрос 18. Запуск bowtie2 и сохранение stderr в файл Ответ: echo "..." > bowtie.log
Вопрос 19. Что будет, если в другой вкладке набрать `fg` после приостановки процесса? Ответ: Терминал сообщит, что нет процесса для запуска в fg
Вопрос 20. Что случится при вводе `exit` в последней вкладке tmux? Ответ: tmux завершит работу

Вопросы и ответы (Часть 5)

Вопрос 21. Закрытие терминала с запущенным tmux на сервере Ответ: Соединение с сервером прервётся, но работа tmux продолжится
Вопрос 22. Принудительное закрытие вкладки tmux с фоновым процессом Ответ: Вкладка закроется, а вместе с ней пропадёт и запущенный в ней процесс
Вопрос 23. Горячая клавиша для переименования текущей вкладки tmux Ответ: Ctrl+B и , (запятая)
Вопрос 24. Верные утверждения о разделении панелей в tmux Ответ: Команды-"разделения" действуют только в текущей вкладке
