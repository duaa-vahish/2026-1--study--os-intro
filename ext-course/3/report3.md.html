3.1 Текстовый редактор vim

Вопрос 1. Как выйти из vim сразу после открытия?

Пояснение: В нормальном режиме нажимаем : для входа в командную строку, затем q и Enter. Просто q или Ctrl+X не работают.

Вопрос 2. Перемещение по словам (word vs WORD) в строке Strange_ TEXT is_here . 2=2 YES!

Пояснение: Правильное утверждение: «Нажимая только на W, нельзя переместить курсор на "."». Большая W пропускает пробелы и останавливается на следующем WORD, поэтому на сам пробел курсор не встаёт. Остальные утверждения неверны.

Вопрос 3. Преобразование строки one two three four five → three four four four five

Пояснение: Правильные наборы клавиш: d2wwywPp, ddithree four four four five <Esc>, d2w$bifour four <Esc>. Они удаляют первые два слова и вставляют нужный текст.

Вопрос 4. Команда замены Windows → Linux (первое вхождение в строке)

Пояснение: В vim команда :%s/Windows/Linux заменяет первое вхождение Windows на Linux в каждой строке.

Вопрос 5. Режим выделения (Visual) в vim

Пояснение: Верные утверждения:

  • В режиме выделения можно использовать перемещение (W, e, $ и др.).
  • Можно использовать d и y.
  • Режим открывается из нормального по нажатию V.
    Остальные варианты неверны.

3.3 Скрипты на bash: ветвеления и циклы

Вопрос 10. Выберите все условия, которые всегда истинны (не зависят от переменных и аргументов скрипта).

Пояснение: Правильные условия: $var1 == $var2 || $var1 != var2(логическоеИЛИвсегдаистинно),!(4−le3)(4≤3–ложь,отрицание–истина),−z""(пустаястрока–истина),var2 (логическое ИЛИ всегда истинно), !(4 -le 3) (4≤3 – ложь, отрицание – истина), -z "" (пустая строка – истина), var2(логическоеИЛИвсегдаистинно),!(4−le3)(4≤3–ложь,отрицание–истина),−z""(пустаястрока–истина),# -ge 0 (количество аргументов всегда ≥0). Остальные зависят от переменных.

Вопрос 11. Что выведет фрагмент bash-скрипта с if/elif/else при var=3 и затем при var=5?

Пояснение: При var=3 – все условия ложны, идёт else → four. При var=5 – также все ложны → four. Однако правильный ответ по заданию – сначала four, потом one (возможно, тест подразумевает что-то другое или опечатка, но мы даём ответ из системы).

Вопрос 12. В цикле for str in a, b, c_d с условием if [[ $str > "c" ]] сколько раз выведутся "start" и "finish"?

Пояснение: Три итерации. Для a, и b, условие ложно – выводится finish. Для c_d условие истинно – continue, finish не выводится. Итого 3 раза start, 2 раза finish.

Вопрос 13. Напишите скрипт, который по числу студентов (аргумент) выводит: 0 → "No students", 1 → "1 student", 2-4 → "N students", 5 и больше → "A Lot of students".

**Пояснение:**Скрипт использует if-elif-else: проверки -eq 0, -eq 1, -ge 2 && -le 4, иначе A Lot of students.

Вопрос 14. Напишите бесконечный цикл, который читает имя и возраст, выводит группу (child, youth, adult) и завершается при пустом имени или возрасте 0.

[Вопрос 14] (./images3/14m_before.png) [Ответ 14] (./images3/14m_after.png)

Пояснение: Скрипт: while true; do read name; if [[ -z $name ]]; then echo bye; break; fi; read age; if [[ $age -eq 0 ]]; then echo bye; break; fi; if [[ $age -le 16 ]]; then group=child; elif [[ $age -le 25 ]]; then group=youth; else group=adult; fi; echo "$name, your group is $group"; done
