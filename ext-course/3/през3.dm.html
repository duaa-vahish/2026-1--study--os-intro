Вопросы и ответы (3.1 – 3.2)

Вопрос 1. Как выйти из vim сразу после открытия?
Ответ: ":", затем "q", затем "Enter".

Вопрос 2. Перемещение по словам (word vs WORD) – верное утверждение?
Ответ: Нажимая только на W, нельзя переместить курсор на ".".

Вопрос 3. Замена Windows → Linux (первое вхождение в строке) – команда vim?
Ответ: %s/Windows/Linux.

Вопрос 4. Режим выделения (Visual) в vim – верные утверждения?
Ответ: Можно использовать перемещение, команды d и y, открывается по V.

Вопрос 5. История команд во вложенных оболочках (bash → sh → bash)?
Ответ: Только из последнего набора (C).

Вопросы и ответы (3.3 – 3.4)

Вопрос 6. Условия, всегда истинные в bash?
Ответ: $var1 == $var2 || $var1 != $var2, !(4 -le 3), -z "", $# -ge 0.

Вопрос 7. Цикл for str in a, b, c_d – сколько раз "start" и "finish"?
Ответ: 3 раза "start", 2 раза "finish".

Вопрос 8. Скрипт для числа студентов (0 → No students, 1 → 1 student, 2–4 → N students, ≥5 → A Lot of students)?
Ответ: Использовать if-elif-else с проверками.

Вопрос 9. Бесконечный цикл с вводом имени и возраста, группы child/youth/adult?
Ответ: while true; do read name; if [[ -z $name ]]; then break; fi; read age; ...; done.

Вопрос 10. Инструкции let для увеличения a на b?
Ответ: let "a+=b", let a=$a+$b, let a=a+b, let "a=$a+$b".

Вопрос 11. Вывод echo " pwd " в скрипте?
Ответ: pwd (строка, а не результат команды).

Вопрос 12. Проверка кода возврата программы, выводящей в stdout?
Ответ: program; if [[ $? -eq 0 ]]; then ... или if program > file; then ....

Вопрос 13. Функция counter – что выведет echo "counters are $c1 and $c2"?
Ответ: counters are and 110.

Вопрос 14. Скрипт для НОД (алгоритм Евклида)?
Ответ: Функция gcd с циклом while [ $b -ne 0 ]; do t=$b; b=$((a % b)); a=$t; done; echo $a.

Вопрос 15. Калькулятор на bash с операциями + - * / % **?
Ответ: while read op1 oper op2; do case $oper in ... esac; done.

Вопросы и ответы (3.5 – 3.6)

Вопрос 16. find /home/bi -iname "star*" vs -name "star*" – какие файлы найдёт только -iname?
Ответ: Star_Wars.avi (разный регистр).

Вопрос 17. Верные утверждения про -path и -name?
Ответ: «Если заменить -name на -path, результат иногда может остаться таким же» и «-name может найти меньше файлов, чем -path».

Вопрос 18. find /home/bi -mindepth 2 -maxdepth 3 -name "file*" – что найдёт?
Ответ: Ничего (файлы на глубине 1).

Вопрос 19. grep -C 1 vs -A 1 vs -B 1 – какой даст наибольший файл?
Ответ: grep -C 1.

Вопрос 20. grep -E "[xklXKL]?[uU]buntu$" – какие строки подходят?
Ответ: The best OS is Xubuntu, I prefer Kubuntu.

Вопрос 21. Что будет, если в sed -n "/[a-z]*/p" убрать -n?
Ответ: Будут выведены все строки файла.

Вопрос 22. Инструкция sed для замены аббревиатур (две и более заглавные буквы) на "abbreviation"?
Ответ: sed 's/\<[A-Z]\{2,\}\>/abbreviation/g' input.txt > edited.txt.

Вопрос 23. Опция gnuplot для сохранения графиков после выхода?
Ответ: -p или --persist.

Вопрос 24. gnuplot: set key autotitle columnhead и plot без заголовков – название ряда и число точек?
Ответ: Название "noname", 10 точек.

Вопрос 25. gnuplot: установка делений на оси OX по переменным x1,x2,x3 с подписями "point 1, value ..."?
Ответ: set xtics ("point 1, value ".x1 x1, "point 2, value ".x2 x2, "point 3, value ".x3 x3).
