4. Terminal: основы

Вопрос 11: Команды, эквивалентные ls -A --human-readable -l /some/directory

Пояснение:
Эквивалентность означает, что команда выполняет то же действие с теми же опциями.

  • -A = --almost-all (показывать все файлы, кроме . и ..).
  • --human-readable = -h (отображать размеры в удобном формате, например, 1K, 2M).
  • -l — длинный формат вывода (права доступа, владелец, размер, дата).
  • /some/directory — целевая директория.
  • Правильные команды — те, которые содержат эти же опции и путь в любом порядке. Все предложенные варианты (кроме последнего, где отсутствует путь) подходят:
  • ls -h -A -l /some/directory
  • ls -Ahl /some/directory (опции объединены в одну)
  • ls -human-readable -A -l /some/directory (длинные опции)
  • ls -almost-all -human-readable -l /some/directory
  • ls -A -human-readable -l (нет пути /some/directory, поэтому не эквивалентна).

Вопрос 12: Вывести содержимое /home/bi/Downloads из /home/bi/Documents

Пояснение:
Из директории /home/bi/Documents:

  • ls ../Downloads — .. поднимается на уровень выше (в /home/bi), затем переходит в папку Downloads.
  • ls ~/Downloads — символ ~ заменяется на домашнюю директорию /home/bi.
  • ls ./Downloads — неверно, так как внутри Documents нет подкаталога Downloads.
  • ls /home/bi/Do* — неверно, так как маска Do* найдёт и Documents, и Downloads (оба начинаются с Do), а нужно только содержимое Downloads.

Вопрос 13: Команда для удаления директорий

Пояснение:

  • rm -r (рекурсивное удаление) — удаляет директорию вместе со всем её содержимым. Это правильный ответ.
  • rm -f — удаляет файлы без подтверждения, но не работает с директориями.
  • mv — перемещает/переименовывает.
  • mkdir -r — такой опции нет (правильно mkdir -p для создания родительских директорий).

5. Запуск исполняемых файлов

Вопрос 14: Что будет после firefox, затем exit?

Пояснение:
Когда мы запускаем firefox из терминала, терминал переходит в режим ожидания, пока Firefox не закроется. Если затем ввести команду exit (которая завершает текущий сеанс терминала), то терминал закроется, а Firefox продолжит работать как отдельный процесс.
Таким образом, результат: Terminal закроется, Firefox продолжит работу.

Вопрос 15: Чему эквивалентен запуск с &?

Пояснение:
Символ & в конце команды запускает программу в фоновом режиме, освобождая терминал для других команд.
Того же эффекта можно достичь вручную:

  1. Запустить программу обычным способом (она займёт терминал).
  2. Приостановить её нажатием Ctrl+Z.
  3. Отправить её в фон командой bg.
    Таким образом, эквивалентная последовательность: Запуск, Ctrl+Z, bg.

Вопрос 18: Какие команды запишут stderr в file.txt?

Пояснение:
Для перенаправления потока ошибок (stderr) используется конструкция 2>.

  • program 2> file.txt — перенаправляет stderr в файл, перезаписывая его содержимое.
  • program 2>> file.txt — перенаправляет stderr в файл, добавляя данные в конец.
    Остальные варианты:
  • program >> file.txt — перенаправляет stdout (не stderr).
  • program < file.txt — перенаправляет ввод.
  • program file.txt <2 — неверный синтаксис.

7. Скачивание файлов из интернета

Вопрос 20: Где окажется картинка после wget -P /home/alex/Pictures -O 1.jpg ...?

Пояснение:
Команда wget имеет опции:

  • -P /home/alex/Pictures — задаёт каталог, в который будет сохранён файл.
  • -O 1.jpg — задаёт имя выходного файла.
    Таким образом, изображение будет сохранено как /home/alex/Pictures/1.jpg.
    Исходное имя (example.jpg) игнорируется.

Вопрос 21: Опция wget для подавления сообщений

Пояснение:
Опция -q (или --quiet) включает тихий режим, при котором wget не выводит никаких сообщений (Resolving..., Connecting..., HTTP-запросы, прогресс-бар).

  • -nv (no-verbose) — отключает детальный вывод, но некоторые сообщения всё же показываются.
  • -v (verbose) — наоборот, включает подробный вывод.

Вопрос 22: Что скачает wget -r -l 1 -A jpg?

Пояснение:

  • -r — рекурсивная загрузка (следует по ссылкам).
  • -l 1 — глубина рекурсии 1 (загружается только указанная страница и прямые ссылки с неё).
  • -A jpg — принимает только файлы с расширением .jpg.

В результате wget загрузит HTML-страницы для навигации (чтобы найти ссылки на изображения), но сохранит только файлы .jpg. Остальные файлы (.png, .html) не сохраняются.

8. Работа с архивами

Вопрос 23: Отличие gzip от zip (по умолчанию)

Пояснение:
При сжатии без дополнительных опций:

  • gzip сжимает один файл и удаляет исходный (остаётся только .gz-архив).
  • zip сжимает файл(ы) и сохраняет исходные файлы (добавляет .zip-архив рядом).
    Это основное различие в поведении по умолчанию.

Вопрос 24: Какие архиваторы могут создать архив из директории?

Пояснение:

  • zip может упаковывать целые директории рекурсивно (например, zip -r archive.zip mydir/).
  • tar предназначен именно для создания архивов из директорий (например, tar -cf archive.tar mydir/).
  • gzip работает только с отдельными файлами; для директории его нужно комбинировать с tar (получается tar.gz). Поэтому правильные ответы — zip и tar.

Вопрос 25: Опции tar для my_archive.tar.bz2

Пояснение:
Опции tar:

  • -c — создать архив (create).
  • -j — использовать сжатие bzip2 (расширение .bz2).
  • -f — указать имя файла.

Таким образом, правильный набор: -cjf.

  • -czf — использовало бы сжатие gzip (.gz).
  • -xjf — распаковывает (x), а не создаёт.
  • -xzf — распаковывает gzip.
  • -wtf — неверные опции.

  • world
  • The "world" is not enough (кавычки не влияют)
  • The world is not enough
